The `NativeVideoPlayerController` exposes three load methods — `loadUrl`, `loadFile`, and the generic backward-compatible `load`. `loadUrl` and `load` accept optional HTTP headers, DRM configuration, sidecar subtitles, and a native resume position. `loadFile` is a focused helper that takes only a local file path and prepends `file://` automatically. All methods route through the same internal pipeline.

## Load Methods

<Tabs>
  <Tab title="loadUrl">
    Use `loadUrl` for any remote resource: HLS manifests, MP4 files, or any format the native player supports. All parameters are optional except `url`.

    ```dart
    // Simple HLS stream
    await controller.loadUrl(
      url: 'https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8',
    );

    // MP4 with custom headers and a native resume position
    await controller.loadUrl(
      url: 'https://cdn.example.com/lesson.mp4',
      headers: {
        'Authorization': 'Bearer your-token',
        'Referer': 'https://example.com',
      },
      startAt: const Duration(minutes: 4, seconds: 15),
    );

    // DRM-protected HLS (iOS FairPlay)
    await controller.loadUrl(
      url: 'https://cdn.example.com/protected.m3u8',
      drmConfig: {
        'type': 'fairplay',
        'licenseUrl': 'https://license.example.com/get',
        'certificateUrl': 'https://cert.example.com/fairplay.der',
        'headers': {'Authorization': 'Bearer <token>'},
      },
    );

    // DRM-protected HLS (Android Widevine)
    await controller.loadUrl(
      url: 'https://cdn.example.com/protected.m3u8',
      drmConfig: {
        'type': 'widevine',
        'licenseUrl': 'https://license.example.com/widevine',
        'headers': {'Authorization': 'Bearer <token>'},
      },
    );
    ```

    **Signature:**
    ```dart
    Future<void> loadUrl({
      required String url,
      Map<String, String>? headers,
      Map<String, dynamic>? drmConfig,
      Duration? startAt,
      bool force = false,
    })
    ```
  </Tab>
  <Tab title="loadFile">
    Use `loadFile` for videos already on the device. Pass an absolute filesystem path — the method prepends `file://` automatically if it is not already present.

    ```dart
    import 'package:path_provider/path_provider.dart';

    // Load a downloaded video from the app's documents directory
    final dir = await getApplicationDocumentsDirectory();
    await controller.loadFile(path: '${dir.path}/my_video.mp4');

    // Android — DCIM or external storage
    await controller.loadFile(
      path: '/storage/emulated/0/DCIM/Camera/video.mp4',
    );

    // iOS — photos library or documents folder
    await controller.loadFile(
      path: '/var/mobile/Media/DCIM/100APPLE/IMG_0042.MOV',
    );
    ```

    **Signature:**
    ```dart
    Future<void> loadFile({required String path})
    ```

    <Note>
      `loadFile` does not accept HTTP headers or DRM config — those are only meaningful for remote URLs. Use `load(url: 'file:///...')` if you need the `force` flag on a local file.
    </Note>
  </Tab>
  <Tab title="load (generic)">
    The original generic `load` method accepts both remote URLs and `file://` URIs and is the most flexible. It is the method called internally by both `loadUrl` and `loadFile`.

    ```dart
    // Remote HLS
    await controller.load(
      url: 'https://example.com/video.m3u8',
    );

    // Local file via file:// scheme
    await controller.load(
      url: 'file:///path/to/video.mp4',
    );

    // With all optional parameters
    await controller.load(
      url: 'https://example.com/video.mp4',
      headers: {'Referer': 'https://example.com'},
      startAt: const Duration(seconds: 90),
      sidecarSubtitles: const [
        NativeVideoPlayerSidecarSubtitle.url(
          'https://example.com/subs_en.vtt',
          language: 'en',
          label: 'English',
        ),
      ],
    );

    // Force-replace the currently loaded video (e.g. playlist advance)
    await controller.load(
      url: 'https://example.com/episode2.mp4',
      force: true,
    );
    ```

    **Signature:**
    ```dart
    Future<void> load({
      required String url,
      Map<String, String>? headers,
      Map<String, dynamic>? drmConfig,
      List<NativeVideoPlayerSidecarSubtitle>? sidecarSubtitles,
      Duration? startAt,
      bool force = false,
    })
    ```
  </Tab>
</Tabs>

## Supported Formats

The plugin delegates to the native player on each platform, so supported formats mirror platform capabilities.

| Format | iOS (AVFoundation) | Android (ExoPlayer) | Notes |
|--------|:------------------:|:-------------------:|-------|
| HLS `.m3u8` | ✅ | ✅ | Adaptive bitrate, quality selection |
| MP4 | ✅ | ✅ | Most widely supported |
| MOV | ✅ | ✅ | QuickTime container |
| M4V | ✅ | ✅ | iTunes video format |
| WebM | ❌ | ✅ | VP8/VP9 codec |
| MKV | ❌ | ✅ | Matroska container |
| `file://` local | ✅ | ✅ | Absolute device path |
| `asset://` | ✅ | ✅ | Flutter asset bundle |

<Note>
  Quality selection and adaptive bitrate streaming (ABR) are only available for HLS streams. MP4 and other progressive formats play at their native, fixed quality.
</Note>

## Resume Positions with `startAt`

Passing `startAt` applies the seek position **natively, before the first frame is decoded.** There is no visible backward-seek animation; the video starts playing exactly at the requested position.

```dart
// Resume a course video from a persisted checkpoint
final savedPosition = await storage.load(videoId); // e.g. Duration(minutes: 12)

await controller.load(
  url: 'https://cdn.example.com/lesson-3.mp4',
  startAt: savedPosition,
);
```

For automatic checkpoint persistence, pair `startAt` with `PositionCheckpoints`:

```dart
final checkpoints = PositionCheckpoints(
  controller,
  interval: const Duration(seconds: 5),
  onCheckpoint: (position) => storage.save(videoId, position),
);
// Dispose with the controller to flush the final position:
checkpoints.dispose();
```

<Tip>
  Because `startAt` is applied natively, it works even when `autoPlay: false`. The player is positioned at the correct timestamp and waits for an explicit `play()` call.
</Tip>

## Custom HTTP Headers

Any header accepted by the server can be passed. The headers are forwarded for **every** segment request (manifests, TS/fMP4 segments, initialization maps), not just the initial manifest fetch.

```dart
await controller.loadUrl(
  url: 'https://cdn.example.com/protected.m3u8',
  headers: {
    'Authorization': 'Bearer eyJhbGciOiJSUzI1NiJ9...',
    'Referer': 'https://example.com',
    'X-Custom-Header': 'my-value',
  },
);
```

## DRM Configuration

DRM is configured via a `Map<String, dynamic>` passed as `drmConfig`. The map shape is the same for `load` and `loadUrl`. `loadFile` does not accept `drmConfig` — local files are not DRM-protected.

| Parameter | Type | Required | Platform | Description |
|-----------|------|:--------:|----------|-------------|
| `type` | `String` | ✅ | Both | `'fairplay'`, `'widevine'`, `'aes-128'`, or `'clearKey'` |
| `licenseUrl` | `String` | ✅* | Both | License server URL (*not needed for `aes-128`) |
| `certificateUrl` | `String` | ✅ iOS FairPlay | iOS | FairPlay certificate `.der` URL |
| `headers` | `Map<String,String>` | No | Both | Auth headers for license requests |

<Tabs>
  <Tab title="FairPlay (iOS)">
    ```dart
    await controller.loadUrl(
      url: 'https://cdn.example.com/fairplay.m3u8',
      drmConfig: {
        'type': 'fairplay',
        'licenseUrl': 'https://license.example.com/fairplay',
        'certificateUrl': 'https://cert.example.com/fairplay.der',
        'headers': {
          'Authorization': 'Bearer <token>',
        },
      },
    );
    ```
  </Tab>
  <Tab title="Widevine (Android)">
    ```dart
    await controller.loadUrl(
      url: 'https://cdn.example.com/widevine.m3u8',
      drmConfig: {
        'type': 'widevine',
        'licenseUrl': 'https://license.example.com/widevine',
        'headers': {
          'Authorization': 'Bearer <token>',
          'Content-Type': 'application/octet-stream',
        },
      },
    );
    ```
  </Tab>
  <Tab title="AES-128">
    ```dart
    // AES-128 keys are extracted automatically from the HLS manifest.
    // No licenseUrl or certificateUrl needed.
    await controller.loadUrl(
      url: 'https://cdn.example.com/aes128-stream.m3u8',
      drmConfig: {
        'type': 'aes-128',
      },
    );
    ```
  </Tab>
</Tabs>

<Warning>
  DRM errors surface through the activity event stream as `PlayerActivityState.error`. Always add an activity listener before calling `initialize()` so you catch license-server failures.

  ```dart
  controller.addActivityListener((event) {
    if (event.state == PlayerActivityState.error) {
      final message = event.data?['message'] as String?;
      print('Error: $message');
    }
  });
  await controller.initialize();
  ```
</Warning>

## Always Initialize Before Loading

The controller must be initialized before any load call. The `initialize()` method waits for the native platform view to be ready before returning.

```dart
@override
void initState() {
  super.initState();
  _controller = NativeVideoPlayerController(id: 1, autoPlay: true);
  _initPlayer();
}

Future<void> _initPlayer() async {
  await _controller.initialize();
  await _controller.loadUrl(
    url: 'https://test-streams.mux.dev/x36xhzz/x36xhzz.m3u8',
  );
}
```
