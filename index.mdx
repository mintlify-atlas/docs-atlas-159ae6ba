**better_native_video_player** is a Flutter plugin that brings true native video playback to iOS and Android. On iOS it uses `AVPlayerViewController`; on Android it uses ExoPlayer (Media3). The result is hardware-accelerated video with adaptive HLS streaming, DRM, Picture-in-Picture, AirPlay, Chromecast, offline downloads, and fine-grained performance tuning — all from a single Dart API.

## Quick installation

```yaml pubspec.yaml
dependencies:
  better_native_video_player: ^1.5.2
```

Then run `flutter pub get` and follow the [platform setup guide](/platform-setup) to configure iOS and Android.

## Platform support

| Platform | Minimum Version | Video Engine |
|----------|----------------|--------------|
| iOS | 12.0+ | AVFoundation / AVPlayerViewController |
| Android | API 24+ (Android 7.0) | ExoPlayer (Media3) |

<Note>
  The package is also WASM compatible — it works with the Flutter Web Assembly runtime.
</Note>

## Get started

<Steps>
  <Step title="Install the package">
    Add `better_native_video_player` to your `pubspec.yaml` and run `flutter pub get`.
  </Step>
  <Step title="Configure your platform">
    Follow the [Platform Setup](/platform-setup) guide to add the required iOS `Info.plist` entries and Android permissions.
  </Step>
  <Step title="Create a controller and widget">
    Create a `NativeVideoPlayerController`, call `initialize()`, load a URL, and embed `NativeVideoPlayer` in your widget tree.
  </Step>
  <Step title="Add advanced features">
    Explore [DRM](/guides/drm), [Chromecast](/guides/chromecast), [offline downloads](/guides/offline-downloads), and [performance tuning](/guides/performance) as needed.
  </Step>
</Steps>
