`better_native_video_player` is a Flutter plugin that delivers true native video playback on both iOS and Android. Instead of rendering video through a Flutter texture or web-based fallback, it embeds platform-native player components directly in your widget tree — AVPlayerViewController on iOS and ExoPlayer (Media3) on Android — giving you the performance, codec support, and system integration that users expect on each platform.

## Platform Support

The plugin targets modern OS versions to take advantage of native PiP APIs and Media3.

| Platform | Minimum Version      | Native Player         |
|----------|---------------------|-----------------------|
| iOS      | 12.0+               | AVFoundation / AVPlayerViewController |
| Android  | API 24+ (Android 7.0) | ExoPlayer (Media3)   |

<Note>
  Picture-in-Picture requires iOS 14.0+ on iOS and Android 8.0+ (API 26+) on Android. Automatic PiP on iOS requires iOS 14.2+.
</Note>

## Architecture

The plugin bridges Flutter and the platform player through a pair of channels per player view:

- **MethodChannel** — Flutter → Native commands (play, pause, seek, setQuality, etc.)
- **EventChannel** — Native → Flutter state updates (position ticks, buffering, PiP, AirPlay)

### iOS

On iOS the plugin registers a `FlutterPlatformView` backed by a full `AVPlayerViewController`. This means you get the native playback pipeline including:

- `AVFoundation` for decoding and HLS manifest handling
- `AVPictureInPictureController` for PiP
- `MPNowPlayingInfoCenter` for Control Center / lock-screen integration
- Hardware-accelerated DRM via FairPlay Streaming

### Android

On Android each player view hosts an ExoPlayer (Media3) instance surfaced through a `PlatformView` with an Android `View`. Key integrations include:

- Media3 HLS extension for adaptive bitrate streaming
- `MediaSessionService` for lock-screen notifications
- `floating` package (v6) for Picture-in-Picture management
- Widevine CDM for DRM-protected streams
- Optional LRU disk cache via Media3's `CacheDataSource`
